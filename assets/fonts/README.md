# Public Sans

`PublicSans-Regular.ttf`, used by `tools/generate_icon.py` to draw the app's mark.

Committed rather than fetched so the icon is reproducible with no arguments and no
network — the same reason [LightFog](https://github.com/gi-os/LightFog) keeps its
copy in `assets/fonts`. It is a build-time asset only; the font is not bundled
into the APK.
